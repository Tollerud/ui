the rule

If it's yellow,
you can
click it.

Yellow is not decoration — it is the interaction layer. Everything else is near-black, grey and one hairline rule. That single constraint is what keeps 105 components looking like one product.

#FFFF00 #0A0A0A #121212 #333333 #AAAAAA #F5F5F5
01
Dark-first

Design starts in the dark. Light mode is a faithful translation, not the default.

02
One color pop

No rainbows. State colors stay muted so the signal never competes with noise.

03
Sharp when it counts

Subtle radius, full-round only for pills. Sharp corners hold the noir feel.

04
Glow with purpose

Yellow glow appears on hover and active states only. Never ambient.

05
Terminal personality

The ❯ prefix and mono type signal: this is a tool, not a brochure.
